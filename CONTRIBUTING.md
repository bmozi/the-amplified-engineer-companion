# Contributing

The book is the canonical source. Please use issues for corrections, broken
links, unclear instructions, or accessibility barriers. Do not include private
company data, credentials, unpublished manuscript material, or personal data.

For a proposed correction, identify the exact file and section, what you
expected, what you observed, and why the change matters. Open an issue before a
substantial pull request so scope and licensing can be confirmed.

Before submitting a change, run:

```bash
python3 scripts/validate_repository.py
```

Written contributions are accepted under CC BY-NC-SA 4.0. Executable scripts
must carry the MIT notice used in this repository.
