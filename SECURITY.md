# Security Policy

These are educational worksheets, not a deployable system or security
certification. Do not put credentials, regulated data, customer information,
or proprietary system details into a public issue or an unapproved AI system.

Report a suspected repository vulnerability through a
[private security advisory](https://github.com/bmozi/the-amplified-engineer-companion/security/advisories/new),
not a public issue. No response-time or remediation SLA is promised.
