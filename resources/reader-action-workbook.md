# The Amplified Engineer Reader Action Workbook

This workbook turns each chapter into a durable change in practice. Use one
real work item throughout when possible. A low-consequence, reversible task
reveals more than a toy demonstration because it carries genuine context,
evidence, and ownership.

Do not use the workbook as an employee ranking system. Record decisions and
conditions, not a verdict about whether a person is “good at AI.”
