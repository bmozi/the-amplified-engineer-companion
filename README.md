# The Amplified Engineer — Reader Companion

Practical worksheets for turning AI's speed into better judgment, safer
delegation, visible evidence, and learning that lasts.

This is the public companion to *The Amplified Engineer: Build More with AI —
Without Losing Judgment, Quality, or Trust* by John Briggs. The book explains
the ideas; these materials help you apply them to one real task.

> **Series:** The Accountable AI Engineering Series — Book 1
> **Permanent companion URL:** https://github.com/bmozi/the-amplified-engineer-companion

## Start here

1. Open the [`Reader Action Workbook`](resources/reader-action-workbook.md).
2. Choose one low-consequence, reversible task that matters to you.
3. Use only the worksheet paired with the chapter you are reading.
4. End with a decision, an evidence record, or a safer boundary—not a score.

For a single AI-assisted task that felt fast but required hidden repair, use
the [`Almost-Right Tax Ledger`](resources/almost-right-tax-ledger.md). It is the
resource referenced in Chapter 13.

The worksheets are diagnostic aids, not employee rankings, compliance
certificates, or safety guarantees. Do not put secrets, regulated data, or
proprietary material into a public issue or an unapproved AI system.

## Download and versions

GitHub renders every worksheet directly in a browser. Readers who prefer an
offline package can download the versioned ZIP from the
[latest release](https://github.com/bmozi/the-amplified-engineer-companion/releases/latest).
See [`EDITION-MAP.md`](EDITION-MAP.md) for the relationship between a companion
release and the published book.

Human usability evidence is tracked separately from automated checks. See the
[`External Reader Usability Pass`](READER-USABILITY-PASS.md) for the current
protocol and honest completion criteria.
